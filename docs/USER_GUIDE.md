# WXDataStudio 使用教程

软件里内置了同一份教程：右上角【使用教程】随时打开。下面是文字版。

## 六步流程

### 1. 把手机上的记录读到电脑

数据线连好手机，点右上角【读取微信记录】。软件会自动暂停微信、给手机上的记录做一份只读备份，然后读出联系人和聊天列表。这一步不改动手机里的任何内容。

### 2. 选一个聊天

左边是聊天列表，点一个联系人或群，中间就会像微信一样显示内容：自己发的在右边绿色气泡，对方发的在左边。上面的搜索框按名字找人，中间第二个搜索框在当前聊天里搜内容。

### 3. 补一条被删掉的记录

聊天底部有一个输入框，和微信一样：打完字点【发送】就加进聊天。左边可以选【我发送】还是【对方发送】。要补图片、语音、文件、表情、位置、名片、链接，点输入框左边的【＋】。

### 4. 改一条记录

点中间任意一条消息，它当场变成输入框，直接改字，改完点【保存】；不想改了点【取消】。内容下面还有一行【时间】，按 `2026-09-20 14:30` 的样子改，保存后这条记录会自动按新时间排到对应位置。要换图片点【换附件】，要删掉这条点【删除这条】。所有类型都能改，包括红包、转账、收付款记录（标注“交易类”，改动留痕）。

### 5. 改错了就撤销

气泡里的【取消】放弃本次修改；已保存的改动可以展开右侧【更多信息 → 撤销这条修改】恢复原样。“新增”“已修改”标记能一眼看出动过哪些。

### 6. 同步回手机微信

点右上角【写回手机】。软件会先备份手机上的原库，再把改好的记录写回去，重启微信，最后把手机数据库读回来逐条核对。写的过程中不要拔数据线；手机上会留一份 `EnMicroMsg.db.wxds-backup-时间戳` 原库备份，随时能还原。

## 更多功能（右上角【更多】）

- 选择电脑上的备份 / 重新读取当前备份
- 导出这段聊天（HTML + JSON，只保存在本机）
- 生成回滚包、检查备份完整性、手机体检
- 查看数据库信息、手动输入数据库密钥、恢复密钥诊断
- 迁移准备检查、运行只读自检

## 常见问题

- 点【读取微信记录】没反应：检查数据线、手机是否允许 USB 调试；底部状态栏会显示当前进行到哪一步。
- 改完手机没变化：改动先保存在电脑上，点【写回手机】确认后才同步。
- 图片显示“附件在手机端”：手机里没有这个文件的缓存，文字内容照常，可用【选择文件】从电脑换一张。
- 改了转账/红包金额，点进去提示“当前使用人数过多，请稍后再试”：这是正常的。聊天里显示的是本地文字，而转账详情页由微信服务器提供，本地改不了金额；服务器上那笔交易没有变，客户端就只能弹这个兜底提示。
- 改完过一会儿又变回原样：微信启动后会按“服务器编号”重新同步消息，把服务器上的版本写回本地。软件现在已经处理：被你改过的那条消息会清掉服务器编号，微信就把它当成本地消息，改动不再被覆盖（转账/红包的详情页仍以服务器为准）。
- 会不会改坏原记录：读取用副本不动原库，写回前先备份，还能撤销。
