# WXDataStudio 使用教程

软件里内置了同一份教程：右上角【使用教程】随时打开。下面是文字版。

## 六步流程

### 1. 把手机上的记录读到电脑

数据线连好手机，点右上角【读取微信记录】。软件会自动暂停微信、给手机上的记录做一份只读备份，然后读出联系人和聊天列表。这一步不改动手机里的任何内容。

### 2. 选一个聊天

左边是聊天列表，点一个联系人或群，中间就会像微信一样显示内容：自己发的在右边绿色气泡，对方发的在左边。上面的搜索框按名字找人，中间第二个搜索框在当前聊天里搜内容。

### 3. 补一条被删掉的记录

点中间上方的【＋ 添加消息】，选类型（文字、图片、视频、语音、文件、表情、位置、名片、链接、引用）。图片类会先让你从电脑里选文件，其它类型生成草稿后在右边改内容。

### 4. 改一条记录

在中间点一条消息，右边出现【修改这条消息】：直接改内容，需要时换附件、改时间，然后点【保存修改】。所有类型都能改，包括红包、转账、收付款记录（会标注“交易类”，改动留痕）。不点保存就不生效。

### 5. 改错了就撤销

点右边【撤销这条修改】：改过的恢复原样，新补的记录会被删掉。“新增”“已修改”标记能一眼看出动过哪些消息。

### 6. 同步回手机微信

点右上角【写回手机】。软件会先备份手机上的原库，再把改好的记录写回去，重启微信，最后把手机数据库读回来逐条核对。写的过程中不要拔数据线；手机上会留一份 `EnMicroMsg.db.wxds-backup-时间戳` 原库备份，随时能还原。

## 更多功能（右上角【更多】）

- 选择电脑上的备份 / 重新读取当前备份
- 导出这段聊天（HTML + JSON，只保存在本机）
- 生成回滚包、检查备份完整性、手机体检
- 查看数据库信息、手动输入数据库密钥、恢复密钥诊断
- 迁移准备检查、运行只读自检

## 常见问题

- 点【读取微信记录】没反应：检查数据线、手机是否允许 USB 调试；底部状态栏会显示当前进行到哪一步。
- 改完手机没变化：改动先保存在电脑上，点【写回手机】确认后才同步。
- 图片显示“附件在手机端”：手机里没有这个文件的缓存，文字内容照常，可用【选择文件】从电脑换一张。
- 会不会改坏原记录：读取用副本不动原库，写回前先备份，还能撤销。
