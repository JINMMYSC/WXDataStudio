# WXDataStudio 产品规格 v0.1

## 1. 产品定位

WXDataStudio 是一个面向个人数据整理、备份、查看、迁移和本地工作副本编辑的 Windows 桌面工具。首个正式适配环境固定为：

- Device: Xiaomi MIX 2S (polaris)
- MIUI: V10.3.5.0.PDGCNXM
- Android: 9 / SDK 28
- ABI: arm64-v8a
- Root: Magisk
- Bootloader: unlocked
- WeChat package: com.tencent.mm
- WeChat version: 8.0.76
- versionCode: 3141
- APK SHA-256: `04792eb19a566395a9fabee9a50be80245826cb774ec64637a22f7f28acd4054`
- Adapter ID: `wechat-android-8.0.76-3141`

目标流程：Android 设备只读快照 -> Windows 工作副本 -> 解析/整理/编辑 -> 完整性检查 -> 可回滚输出 -> Android 验证 -> 使用微信自身的聊天记录迁移功能迁移至 iPhone。

## 2. 安全与数据原则

1. 永远保留原始只读快照，不在唯一原始数据上直接操作。
2. 所有写操作仅针对工作副本，写回前强制生成回滚点。
3. 所有修改记录审计日志：时间、对象、旧值、新值、操作批次、快照 ID。
4. 交易/凭证类消息（红包、转账、收付款、账单、官方支付状态）默认只读；可在本地演示/导出副本中展示，但不提供伪造真实凭证的写回能力。
5. 不把微信 APK 二进制提交到公开仓库，只保存版本号、SHA-256 和适配清单。
6. 任何写回前必须执行数据库、索引、附件、时间线和文件权限检查。

## 3. 主界面信息架构

主窗口采用四区布局：

- 顶部：设备 / 快照 / 导入 / 导出 / 检查 / 设置
- 左侧：会话列表与搜索
- 中间：聊天时间线
- 右侧：消息属性与编辑器
- 底部：完整性检查、日志、风险提示、后台任务状态

## 4. 页面清单

### 4.1 首页 / 控制台

显示：
- 手机连接状态
- 设备型号、Android、MIUI、Root、Bootloader
- 当前微信版本和 APK SHA-256
- 当前账号目录
- 最近一次完整快照
- 当前工作副本状态
- Adapter 兼容状态

操作：
- 连接/刷新设备
- 环境检测
- 创建只读快照
- 打开工作副本
- 恢复快照
- 打开日志

### 4.2 设备页

功能：
- ADB 检测
- USB 调试授权检测
- Root/Magisk 检测
- 微信安装路径检测
- 微信版本和签名信息读取
- 账号数据目录检测
- APK 版本基线校验
- 输出设备环境报告

### 4.3 快照页

快照对象：
- EnMicroMsg.db / WAL / SHM
- 相关索引数据库
- 关键 shared_prefs
- 账号目录元数据
- 附件索引
- 版本信息和文件哈希

功能：
- 创建快照
- 列表浏览
- 快照差异比较
- 恢复
- 校验 SHA-256
- 标记“最后已验证可启动”快照

### 4.4 会话页

显示：
- 联系人
- 群聊
- 文件传输助手
- 公众号/服务号
- 系统会话

功能：
- 名称、备注、微信号搜索
- 按最后消息时间排序
- 按消息类型、日期、是否有附件筛选
- 最近编辑/异常会话筛选

### 4.5 聊天时间线

支持解析和展示：
- 文本
- 图片
- GIF/表情
- 视频
- 语音
- 文件
- 名片
- 位置
- 链接卡片
- 小程序卡片
- 引用回复
- 撤回提示
- 拍一拍
- 群公告/入群/退群等系统提示
- 通话记录
- 合并转发记录
- 红包/转账/收付款/账单类消息（只读）

### 4.6 右侧消息属性面板

通用字段：
- 本地消息 ID
- 服务端消息 ID（若存在）
- 会话 ID
- 发送方/接收方
- 消息方向
- 消息类型/子类型
- 创建时间/显示时间
- 排序字段
- 发送状态/已读状态
- 引用关系
- 附件引用

可编辑范围（工作副本）：
- 普通文本内容
- 文本换行/@信息
- 非交易类消息时间
- 图片/视频/语音/文件的本地附件引用
- 非敏感展示属性

### 4.7 媒体与附件页

功能：
- 导入图片
- 替换图片
- 预览原图和缩略图
- 导入视频/语音/文件
- 检测缺失附件
- 重新生成缩略图
- 校验文件大小、扩展名、MIME、哈希
- 查找孤立文件和无效引用

支持格式至少覆盖：jpg/png/webp/gif/mp4/amr/silk/mp3/pdf/doc/docx/xls/xlsx/zip。

### 4.8 时间线编辑页

功能：
- 修改单条非交易类消息时间
- 批量平移时间
- 为一段消息重新排时间
- 保持消息顺序单调递增
- 自动检查跨天日期分隔
- 自动更新会话最后消息时间/摘要
- 修改前后时间线预览

### 4.9 搜索页

支持：
- 全局关键词
- 联系人/群
- 日期范围
- 消息类型
- 发送方
- 是否有附件
- 是否已编辑
- 是否存在完整性异常

### 4.10 差异对比页

左右显示：原始快照 vs 工作副本。

高亮：
- 文本变化
- 时间变化
- 附件变化
- 元数据变化
- 新增/删除

支持：
- 单条撤销
- 会话级撤销
- 批次级撤销

### 4.11 完整性检查页

至少检查：
- 数据库可打开
- WAL/SHM 状态
- 主键/索引一致性
- 消息排序
- 会话摘要/最后消息时间
- 引用目标是否存在
- 附件是否存在
- 缩略图/原图引用
- 重复消息/孤儿记录
- 未识别消息类型
- 写回目标 UID/GID/权限/SELinux context

输出：通过 / 警告 / 阻断，并生成可保存报告。

### 4.12 导出页

支持：
- HTML
- JSON
- CSV（结构化索引）
- SQLite 工作副本
- 媒体 ZIP
- 可打印报告

交易/凭证类内容的演示导出必须标记为“本地副本/非原始凭证”。

### 4.13 审计日志页

每次编辑记录：
- 时间
- 操作批次
- 快照 ID
- 会话 ID
- 消息 ID
- 字段
- 旧值
- 新值
- 操作结果
- 完整性检查结果

## 5. 消息类型优先级

P0：文本、图片、普通文件、时间、会话信息、搜索、快照、差异、完整性检查。

P1：视频、语音、表情、引用、链接、位置、名片、群系统消息。

P2：小程序、合并转发、复杂系统卡片、更多媒体索引。

只读类：红包、转账、收付款、账单、支付状态、其他可能作为交易凭证使用的消息。

## 6. 技术架构

- UI: C# / .NET 8 / WPF
- Architecture: MVVM
- Device layer: bundled Android Platform Tools
- Adapter layer: version-specific WeChat adapter
- Storage layer: immutable snapshot + mutable workspace
- DB layer: pluggable WCDB/SQLCipher access provider
- Audit: JSONL + SQLite local audit database
- Integrity engine: rule-based validators

目录建议：

```text

.github/workflows/
```

## 7. Adapter 8.0.76 目标

Adapter 必须明确包含：
- 支持的 package/versionCode/versionName
- APK SHA-256 白名单
- 设备/系统最低要求
- 账号目录识别
- 主数据库/WAL/SHM 定位
- 打开参数提供器
- 消息表/联系人表/会话表字段映射
- 媒体路径映射
- 完整性规则
- 写回前后钩子

任何版本不匹配时，默认阻止写回。

## 8. v0.1 验收标准

v0.1 必须做到：
1. MIX 2S 能被稳定识别。
2. 8.0.76 / 3141 能通过 SHA-256 基线检测。
3. 创建只读快照并验证哈希。
4. 能正确打开一个工作副本。
5. 能显示会话列表。
6. 能显示文本和图片消息。
7. 能搜索消息。
8. 能导出 HTML/JSON。
9. 能执行基础完整性检查。
10. 原始数据全程不被修改。

v0.1 不以“可写回真实微信数据”为验收条件；写回功能必须等读取、解析、快照和回滚机制通过真机回归后再开启。
